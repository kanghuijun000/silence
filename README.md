# SILENCE

모바일 브라우저에서 실행하는 가로 화면 고정 1인칭 3D 미로 탈출 공포 게임.

## 실행
GitHub 저장소의 **Settings → Pages**에서 배포 소스를 `Deploy from a branch`, 브랜치 `main`, 폴더 `/ (root)`로 설정하면 GitHub Pages에서 실행할 수 있습니다. Three.js 모듈은 CDN에서 불러옵니다.

## 조작
- 왼쪽 조이스틱: 이동
- 화면 오른쪽 드래그: 시야 회전
- 달리기 버튼: 달리기
- 감지기 버튼: 배터리 1칸을 사용해 5초간 괴물 확인

## 구현된 시스템
- 매 판 새로 생성되는 연결된 약 50×50 규모 미로, 무작위 시작 위치와 단 하나의 출구
- 1인칭 3D 지하 콘크리트 미로와 모바일 가로 화면 UI
- 괴물의 배회, 소리 발생 지점 조사, 마지막 목격 위치 수색, 시야 확보 시 추격
- 감지기: 5초 탐지, 최대 배터리 5칸, 사용 소리로 괴물이 위치 조사
- 충전기 5개: 1초당 배터리 1칸 충전, 완료 또는 중도 이탈 시 해당 충전기 제거 후 다른 통로에 재생성
- 플레이어 발밑의 삐걱이는 바닥, 금속, 파편, 물웅덩이 소음
- 괴물의 30~60초 간격 자체 소리
- 달리기 최대 10초, 걷는 동안 완전 회복까지 8초
- 달리기를 멈추고 걷는 동안 스태미나가 회복될 때만 숨소리 발생. 회복량이 많을수록 숨소리 지속 시간도 길어지고, 괴물도 숨소리 위치를 들을 수 있음.
- PWA 설치 지원 및 서비스 워커 캐시

## 주의
이 저장소에는 현재 기본 플레이 가능한 첫 구현이 들어 있습니다. 실제 스마트폰 기기별 성능, 터치 감도, 괴물 난이도, 사운드 밸런스는 기기에서 테스트하고 조정해야 합니다.
